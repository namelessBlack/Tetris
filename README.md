# Тетрис

Классический тетрис на Python с интерфейсом на tkinter. Сторонние библиотеки не нужны — достаточно обычного Python 3.10 или новее.

## Запуск

```
python main.py
```

Или открыть `main.py` в PyCharm и нажать Run.

## Управление

| Клавиша | Действие |
|---|---|
| ← → | сдвиг влево / вправо |
| ↓ | быстрее вниз |
| ↑ или X | поворот по часовой стрелке |
| Z | поворот против часовой стрелки |
| Пробел | сбросить фигуру до упора |
| C | убрать фигуру в запас |
| P | пауза |
| R | новая игра |

Буквенные клавиши работают и в русской раскладке.

## Возможности

- Тень показывает, куда упадёт фигура.
- Видна очередь из трёх следующих фигур.
- Фигуру можно убрать в запас и достать позже (один раз, пока не застынет очередная фигура).
- Фигуры выдаются «мешками» по семь штук: каждая из семи появляется по разу, затем мешок наполняется заново.
- Рекорд сохраняется в файле `highscore.txt` рядом с игрой.

## Очки и уровни

| Событие | Очки |
|---|---|
| 1 линия | 100 × уровень |
| 2 линии | 300 × уровень |
| 3 линии | 500 × уровень |
| 4 линии | 800 × уровень |
| Клетка ускоренного падения (↓) | 1 |
| Клетка сброса (пробел) | 2 |

Уровень растёт каждые 10 убранных линий. На первом уровне фигура падает на клетку раз в 800 мс, с каждым уровнем — на 60 мс быстрее, но не быстрее 80 мс.

## Устройство кода

| Файл | Что в нём |
|---|---|
| `main.py` | запуск игры |
| `tetris_logic.py` | правила: поле, фигуры, повороты, очистка линий, очки. Графики здесь нет |
| `tetris_ui.py` | окно, рисование и обработка клавиш |

Логика и интерфейс разделены: `tetris_ui.py` вызывает методы класса `Game` из `tetris_logic.py` (`move`, `rotate`, `hard_drop`, `tick` и другие) и после каждого события перерисовывает экран.

Настройки игры (размер поля, скорость, очки) — константы в начале `tetris_logic.py`; размеры и цвета — в начале `tetris_ui.py`.
